# Ritme

Eigen app voor gewoontes, taken, agenda en een 60-dagen-uitdaging. Werkt als installeerbare web-app (PWA); alle gegevens blijven op je eigen toestel.

- **Op je telefoon:** open de online versie in Chrome → menu ⋮ → *App installeren*.
- **Op je laptop (met AI-coach):** dubbelklik `Start Ritme.cmd` (Node + Ollama nodig).
